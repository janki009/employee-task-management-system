# Employee Task Management System

A beginner-friendly web application for managing employees and tasks.

## Technologies
- HTML5
- CSS3
- JavaScript
- SQL/MySQL schema

## Features
- Add employees
- Create tasks
- Assign tasks to employees
- Set priority and status
- Search tasks
- Filter tasks by status
- Update task status
- Delete tasks
- Dashboard statistics
- Browser localStorage for simple data persistence

## How to Run
1. Open `index.html` in a browser, or use the VS Code Live Server extension.
2. Add employees and tasks and test all features.
3. `database.sql` contains the MySQL database design for learning SQL.
